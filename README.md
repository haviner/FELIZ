# FELIZ
# Como você está para o treino de hoje?
App para Personal Trainer utilizar no dia-a-dia.
Ele detecta o Nível de Prontidão do aluno antes da seção do treino. Um questionário online, feito em HTML, para ser executado em qualquer dispositivo.
O aluno responde 5 perguntas rápidas para entender sua recuperação e ajudar seu personal a planejar a sessão de hoje.
App está disponivel no https://felizdh.netlify.app/ basta copiar o link e mandar para seu aluno.
